# 安可三联 · 私有体验版范围

## 已批准
用户于2026-10-18同意开始图片＋文字极简版。目标是验证参与者是否愿意共同完成一个值得保存的活动后记，不是承诺爆款或盈利。

## 第一条完整流程
创建活动 → 自己完成一张卡（无需邀请也有价值）→ 可选邀请第二、第三位参与者 → 各自添加图片/文字 → 查看共同作品 → 导出PNG → 撤回个人贡献或由创建者删除活动。

## 设计原则
- 默认中文，清晰现代，桌面和手机都可操作。不是后台报表。
- 不强制注册、邮箱、钱包、付费或邀请解锁。
- 图片与文字先有独立价值，协作是自愿增益。没有朋友加入时仍能导出个人纪念卡。
- 即时可见反馈，保存/上传错误保留输入，危险操作只作一次明确确认。
- 原始照片不被发送给第三方模型。演示使用原创虚构素材。

## 权限与隐私
- 创建者、查看者、邀请和个人贡献权限分开；所有随机能力令牌至少128位，不可通过ID推断。
- 创建者密钥不得出现在邀请链接、查看响应、日志或图片URL。URL片段可用于浏览器接收密钥，之后使用Authorization头。
- 撤回会删除该贡献及其服务端图像；删除活动会删除所有贡献/图像并使旧链接失效。已经下载到其他设备的文件无法收回，界面必须说明。
- 重新生成邀请只阻止旧链接新增参与，不暗示清退已有参与者。
- 无第三方分析脚本、外部字体或社交自动发布。图片验证并重编码去除EXIF，限制大小/像素。正文是纯文本，不执行HTML。

## 验收与不支持
必须真实运行并点击创建、上传、邀请、两/三人协作、导出、撤回、删除、刷新恢复与错误路径。导出PNG需验证内容非空、文字不越界、原始照片不变形。不同浏览器上下文模拟独立参与者。
此阶段默认仅本机127.0.0.1服务；测试邀请证明同服务内协作，不证明互联网部署可用。真实跨设备邀请需要后续获准部署和域名/HTTPS/运营准备。

## 不在本轮
公开发布、招募/联系外部用户、真实收费、真实客户媒体、钱包/链上写入、NFT、发币、收益权、内容推荐、开放社区、视频/音频、平台实名认证。
这些边界不妨碍完整本地体验，但不得称为已商业上线。

## 后续需要验证
目标主办方是否愿意组织试用、用户是否自愿邀请朋友、被邀请者是否获得自身价值、重复使用、组织方愿付费。任何合成测试/漂亮UI均不能证明这些商业结论。
